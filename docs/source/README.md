# docs/source - kontekst projektu dla Codex

Ten katalog zawiera aktualny pakiet kontekstowy projektu gry web/PWA 18+ o roboczej nazwie **Afterglow**.

Dokumenty są celowo podzielone tematycznie, żeby Codex mógł szybko znaleźć właściwy kontekst bez czytania jednej wielkiej ściany tekstu, bo najwyraźniej nawet modele językowe zasługują na minimum higieny informacyjnej.

## Konwencja wersjonowania dokumentów

- Dokumenty decyzyjne i kontekstowe mają prefiks daty: `YYYY-MM-DD`.
- Jeśli powstaje nowszy dokument na ten sam temat, nowsza data ma pierwszeństwo.
- `README.md` pełni rolę indeksu.
- `decision-log.md` jest głównym miejscem na nowe, obowiązujące decyzje.
