## Priority Rules

- Accepted decisions in [Decision Log](decisions/decision-log.md) take priority.
- Newer dated decisions take priority over older notes on the same topic.
- MVP scope takes priority over later-stage ideas.
- Unresolved or unsupported details should be marked as `TBD`.
- Historical raw inputs are not canonical unless promoted into these docs.

## Current Project Identity

- Product name: `Afterglow`.
- Repository structure: one monorepo.
- Frontend package: `frontend/`.
- Backend package: `backend/`.

The product name remains a working name unless an accepted decision changes it.
